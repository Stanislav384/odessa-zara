# Зарядки Одессы

Карта зарядных станций Eco Factor, TOKA и GO TO-U в Одессе и Одесской области.

- Сайт: GitHub Pages этого репозитория.
- Общие отметки и примечания хранятся в `data.json`. Менять их может только администратор, у которого есть ключ доступа с правом записи в этот репозиторий. Остальные открывают ссылку и только смотрят.
- Источники: карты TOKA и Eco Factor, каталог Open Charge Map (GO TO-U); схема города и области: © участники OpenStreetMap, OpenMapTiles.
