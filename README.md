# Зарядки Одессы

Карта зарядных станций Eco Factor, TOKA и GO TO-U в Одессе и Одесской области.

- Сайт: Vercel (charge-odessa.vercel.app), запасной адрес — GitHub Pages.
- Общие отметки, примечания и история хранятся в ветке `data`, файл `data.json`. Менять их может только администратор, у которого есть ключ доступа с правом записи в этот репозиторий. Остальные открывают ссылку и только смотрят.
- Источники: карты TOKA и Eco Factor, каталог Open Charge Map (GO TO-U); схема города и области: © участники OpenStreetMap, OpenMapTiles.
